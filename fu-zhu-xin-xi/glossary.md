# 常见术语表

{% hint style="success" %}
**说明**：当前文档的示例均以 BNB Chain 为准，但同样适用于所有 EVM 兼容链，包括 Base、ETH 主网、X Layer、Polygon 及其他 L2 等。

这些网络的底层逻辑与交互方式基本一致，你只需根据实际使用的链，替换对应的网络配置与原生代币，即可按本文档说明来理解这些概念和基础涵义。
{% endhint %}

### 🎯基础概念

| 术语                          | 描述                                  |
| --------------------------- | ----------------------------------- |
| 交易（Tx）                      | 链上状态变更的操作（转账/调用合约）。                 |
| **交易哈希（Tx Hash）**           | **交易的唯一编号，用于查询状态。**                 |
| Nonce                       | 账户已发交易计数；可用相同 Nonce+更高 Gas 替换未确认交易。 |
| Gas / Gas Price / Gas Limit | 执行费用/单价上限；常用单位 Gwei。                |
| BNB 单位                      | 1 BNB = 10^9 Gwei = 10^18 Wei。      |
| RPC 节点                      | 与链交互的入口（HTTP/WS）。                   |
| 确认数                         | 后续新增区块数量，确认越多越安全。                   |
| EOA / 合约账户                  | 外部账户由私钥控制；合约账户由代码控制。                |

### 🔔 代币与标准

| 术语                 | 描述                                                |
| ------------------ | ------------------------------------------------- |
| **BEP-20**         | **BSC 同质化代币标准（类似 ERC-20）。**                       |
| **BEP-721 / 1155** | **NFT 与混合标准（类似 ERC-721/1155）。**                   |
| BEP-2（Beacon 链）    | BNB Beacon Chain 的代币标准（非 EVM），与 BEP-20 不兼容，需桥接转换。 |
| WBNB（Wrapped BNB）  | 把原生 BNB 封装为 BEP-20 代币，便于合约交互。                     |
| Decimals（小数位）      | 代币精度，常见 18。                                       |
| Mint / Burn        | 增发/销毁代币数量。                                        |
| BEP-95（手续费燃烧）      | 网络层将部分 Gas 费用实时销毁，形成 BNB 的通缩机制（与代币合约无关）。          |
| Tokenomics         | 税率、分配、解锁等代币经济设计。                                  |

### 💹 交易与授权

| 术语                         | 描述                          |
| -------------------------- | --------------------------- |
| Approve / Allowance（授权/额度） | 允许合约代为花费你的代币；可随时 Revoke 撤销。 |
| Permit（EIP-2612）           | 用签名授权，省一次上链 approve。        |
| 滑点（Slippage）               | 可容忍的价格变动范围。                 |
| 替换交易（Speed Up/Cancel）      | 用更高 Gas、相同 Nonce 覆盖未确认交易。   |
| Revert（回退）                 | 执行失败但仍消耗 Gas。               |
| Batch/Multicall（批量调用）      | 一次性执行多步操作。                  |

### 🔄 DEX 与流动性（AMM）

| 术语                    | 描述                             |
| --------------------- | ------------------------------ |
| AMM                   | 自动做市模型（如恒定乘积模型），无需订单簿。         |
| 流动性池（LP Pool）         | 两种资产按比例注入，供交易使用。               |
| LP 代币                 | 代表你的池子份额与手续费收益权。               |
| 路由/工厂（Router/Factory） | 交换入口与交易对创建合约。                  |
| 多跳（Multi-Hop）         | 经多个池子换得更优价格。                   |
| 价格影响（Price Impact）    | 你的下单规模对池子价格的即时冲击；影响越大，成交越偏离预期。 |
| 无常损失（IL）              | 做市相对单持的潜在损失。                   |

### 🛡️ 安全必读

| 术语                           | 描述                                            |
| ---------------------------- | --------------------------------------------- |
| **助记词/私钥**                   | **资产根凭证，绝不能截图/粘贴/上传。**                        |
| **无限授权风险**                   | **授权最大值可能被盗用，建议定额授权并定期 Revoke。**              |
| 最大交易/持仓限制（MaxTx / MaxWallet） | 部分代币对单笔交易和单地址持仓设上限；超限会失败或无法卖出，下单前务必确认当前与上限数值。 |
| Rug Pull                     | 撤 LP 或增发抛售致崩盘。                                |
| 黑名单/税率/交易开关                  | 管理员可改，须核对合约权限。                                |
| 可升级代理（Proxy）                 | 可换逻辑合约，需配多签+时间锁。                              |
| 假合约地址                        | 仅认权威来源与官方公告。                                  |
| MEV/三明治                      | 因滑点过大被前后夹击。                                   |
| 空投/尘埃攻击（Airdrop/Dusting）     | 陌生代币小额转入诱导你交互或授权，不要与来源不明的代币交互或授权。             |

{% hint style="info" %}
**最小自查清单：**

* 合约是否已验证？
* 权限是否可改税/黑名单/暂停/增发？
* LP是否锁仓？
* 是否多签+时间锁？
{% endhint %}
