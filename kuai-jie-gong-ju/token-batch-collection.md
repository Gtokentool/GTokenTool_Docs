# 💰 代币批量归集

GTokenTool推出的批量归集工具专为币安智能链（BSC）优化设计，支持BEP20代币和BNB的专项归集，让复杂的手动操作变成全自动链上执行，大幅降低时间和Gas成本。下面我们就来详细拆解这项工具的功能、优势、使用方法以及注意事项。

### 代币批量归集具体流程 <a href="#pi-liang-gui-ji-ju-ti-liu-cheng" id="pi-liang-gui-ji-ju-ti-liu-cheng"></a>

#### 1. 连接钱包 <a href="#id-1.-lian-jie-qian-bao" id="id-1.-lian-jie-qian-bao"></a>

批量归集：[https://robotv2.gtokentool.com/#/collect](https://robotv2.gtokentool.com/#/collect)

进入页面后，选择币安链并点击连接钱包。这里我用测试网演示。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FbMuifwEJ3pguyhT4tWbL%252FSnipaste_2025-11-28_10-55-33.png%3Falt%3Dmedia%26token%3D33a7cbe9-a86e-4815-a0dd-b719258d2c6c\&width=768\&dpr=3\&quality=100\&sign=ad1044be\&sv=2)

连接钱包并选择公链

### 2. 归集代币 <a href="#id-3.-gui-ji-dai-bi" id="id-3.-gui-ji-dai-bi"></a>

选择归集代币，输入代币地址和归集钱包地址。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FkKkcN6O6qIsCRT8aZpe0%252FSnipaste_2025-11-28_11-24-43.png%3Falt%3Dmedia%26token%3D420c28d0-ac90-44e9-b0c8-65bdec0a4463\&width=768\&dpr=3\&quality=100\&sign=57b11cc1\&sv=2)

输入代币地址和接收地址

点击“`导入钱包`”，输入要归集的钱包私钥，一行一个。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FbUWArlH9iBIWA9ZTT7mW%252FSnipaste_2025-11-28_11-02-35.png%3Falt%3Dmedia%26token%3Daaf420e7-ce3b-4d7d-8d1f-329866952aa9\&width=768\&dpr=3\&quality=100\&sign=450e5f29\&sv=2)

导入钱包

导入成功后，下面可以看到导入钱包的余额以及代币余额。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FfR4OelKckmoig4yN7pUp%252FSnipaste_2025-11-28_11-26-29.png%3Falt%3Dmedia%26token%3D75ff22fa-cfb1-460e-9501-dd1deaa978d6\&width=768\&dpr=3\&quality=100\&sign=9279c457\&sv=2)

导入钱包成功

点击“`归集`”，点击之后会有弹框显示归集钱包地址，确认无误后点击“`Yes`”，继续交易。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FThl3Qyo22USplgjLMNbr%252FSnipaste_2025-11-28_11-27-19.png%3Falt%3Dmedia%26token%3D4b3ac71d-2b07-4120-ae77-6d12d84bb4ad\&width=768\&dpr=3\&quality=100\&sign=96623015\&sv=2)

确认归集

归集成功会弹出成功提示，点击“`刷新`”可以确认是否归集成功。

![](https://docs.gtokentool.com/~gitbook/image?url=https%3A%2F%2F1523574308-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FaUD1j15UCzdjC6ftyzSr%252Fuploads%252FMc0y68jgk5dYmLalKvN0%252FSnipaste_2025-11-28_11-29-15.png%3Falt%3Dmedia%26token%3D344402e9-cc69-4157-a2c9-0da5d25b834f\&width=768\&dpr=3\&quality=100\&sign=22510304\&sv=2)

归集完成
